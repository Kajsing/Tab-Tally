# Privacy Policy for Tab Tally

Last updated: June 13, 2026

Tab Tally is a small Chrome extension that shows local counts of open tabs, browser windows, and tab groups.

## Data Collection

Tab Tally does not collect, store, sell, transmit, or share personal data.

The extension reads tab, window, and tab group information locally in your browser only to calculate the counts shown in the popup and toolbar badge. This information is not sent to the developer or to any third party.

Tab Tally does not collect browsing history, page URLs, page titles, analytics, advertising identifiers, or crash reports.

## Permissions

Tab Tally requests the `tabGroups` permission so it can count open tab groups and grouped tabs. The extension also uses Chrome's tabs and windows extension APIs to calculate local tab and window counts.

## Remote Services

Tab Tally does not use remote services, external servers, remote code, analytics, ads, affiliate tracking, or third-party SDKs.

## Limited Use

The use of information received from Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Contact

For privacy questions or support, use the support contact provided on the Chrome Web Store listing or the project repository.
